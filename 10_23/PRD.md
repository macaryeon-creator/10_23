# 猜英文單字 App — 產品需求文件（PRD）

- 文件版本：1.0
- 更新日期：2026-10-23
- 狀態：第一版產品規劃，可作為設計與開發依據
- 暫定產品名稱：WordQuest 單字探險
- 平台：iPhone／iOS，使用 SwiftUI 開發
- 介面語言：繁體中文；學習內容為英文

> 已確認需求：透過猜英文單字學習英文。以下玩法、內容數量與學習規則為建議的第一版預設，可依後續回饋調整；本文件不代表功能已完成。

## 1. 產品目標

打造一款每天花 3–5 分鐘即可使用的英文單字學習 App。使用者根據中文意思與英文例句猜出單字，作答後理解用法，再透過錯題複習加深記憶。

核心原則：猜字是學習的入口，記住意思、拼字與用法才是目的。避免只靠隨機猜字母過關，也避免用扣生命或強制倒數造成壓力。

### 目標使用者

- 以繁體中文為主要語言、想建立英文基礎的青少年與成人。
- 大致具備 A1–A2 程度、需要練習常見生活單字的人；此為內容定位，非正式程度檢定。
- 希望利用通勤、休息等零碎時間學習的人。

### 核心需求

| 使用者需求 | 產品回應 |
| --- | --- |
| 背單字容易無聊 | 用線索猜字與即時回饋增加參與感 |
| 看到認得，卻拼不出來 | 讓使用者主動輸入完整英文單字 |
| 猜完仍不知道怎麼用 | 每題提供詞性、中文解釋、例句與翻譯 |
| 學過容易忘記 | 自動安排錯題與間隔複習 |
| 不知道今天要學多少 | 每回合固定 5 題，完成後顯示學習摘要 |

## 2. 第一版範圍（MVP）

### 必須包含

1. 簡短使用說明與首頁。
2. 依生活主題進行 5 題猜字練習。
3. 中文意思、英文填空例句與字母數提示。
4. 英文輸入、答案判定、逐步提示與略過功能。
5. 作答後的單字解說及系統英文朗讀。
6. 結算、錯題複習、間隔複習與基本學習紀錄。
7. 本機儲存、離線使用與基本無障礙支援。

### 暫不包含

- 帳號登入、雲端同步、排行榜與好友競賽。
- 訂閱、廣告、虛擬貨幣及生命值。
- AI 即時出題、聊天老師與自動程度測驗。
- 語音辨識、口說評分、多字片語與多語介面。
- 自訂單字匯入、推播提醒及進階成就系統。

## 3. 核心體驗與流程

首次開啟 → 看懂玩法 → 首頁選擇主題 → 完成 5 題 → 查看結果 → 複習錯題或返回首頁。

後續開啟 → 首頁顯示到期複習數 → 優先複習或開始新練習 → 查看學習進度。

首次使用不要求註冊或通知權限。使用說明只需一頁，內容為「看線索、猜單字、學用法」，可直接開始。

### 單題範例

- 主題：食物
- 中文提示：蘋果
- 英文例句：I eat an _____ every day.
- 字母數：5
- 正確答案：apple
- 完成後顯示：apple／名詞／蘋果；I eat an apple every day.／我每天吃一顆蘋果。

## 4. 猜字規則

### 出題與輸入

- 每回合 5 個不同單字；不足 5 題時使用實際可用題數，不重複湊題。
- 單字限定由 a–z 組成的單一英文詞；首版不收錄空格、連字號或變化形式造成多解的題目。
- 顯示中文意思、挖空英文例句與字母數，不在作答前提供完整例句翻譯或答案朗讀。
- 使用系統英文鍵盤輸入完整答案，關閉自動修正與自動大寫。
- 比對前去除頭尾空白並忽略大小寫；不自動修正拼字。
- 空白答案、包含非英文字母或長度不符時，顯示明確提醒，不計入錯誤次數。
- 英文線索必須足以區分同義詞；上線前人工檢查，每題只接受詞庫指定答案。

### 嘗試與提示

- 每題最多 3 次有效作答。
- 第一次與第二次答錯：保留輸入，顯示「再試一次」與剩餘次數，不立即揭露答案。
- 第三次答錯：顯示答案與解說。
- 「提示」第一次揭露首字母，第二次揭露末字母，之後停用；使用提示不扣作答次數。
- 「看答案」可隨時結束本題，視為需複習。
- 不設倒數、不扣生命值。提交後鎖定判定直到完成處理，避免連點重複計分。

### 結果分類

| 分類 | 條件 | 後續處理 |
| --- | --- | --- |
| 獨立答對 | 首次有效作答即答對，且未用提示 | 計入獨立答對數，安排間隔複習 |
| 練習後答對 | 曾答錯或使用提示後才答對 | 顯示肯定回饋，排入需加強清單 |
| 尚待熟悉 | 3 次皆錯或直接看答案 | 顯示完整解說，排入需加強清單 |

每題結束後必須停留在解說畫面，由使用者按「下一題」繼續。無論答對或答錯，都能閱讀解釋並播放英文單字與完整例句。

## 5. 畫面與功能

### 5.1 首頁

- 顯示今日完成題數、連續學習天數及到期複習單字數。
- 主要按鈕：「開始練習」；次要按鈕：「複習單字」。
- 提供主題選擇，預設「全部主題」。
- 有未完成回合時，提供「繼續練習」；另開新回合前說明將結束目前回合。
- 無到期複習時顯示「今天沒有待複習單字」，仍可開始一般練習。

### 5.2 猜字畫面

- 顯示主題、題數進度（例如 2／5）、中文提示、挖空例句及字母數。
- 提供輸入框、「送出」、「提示」及「看答案」。
- 以文字及圖示呈現正誤，不只依靠紅綠顏色。
- 離開畫面時保存目前題目、輸入、提示與作答次數。

### 5.3 單字解說

- 顯示正確拼字、詞性、中文意思、完整英文例句與繁體中文翻譯。
- 提供「播放單字」及「播放例句」。
- 顯示本題結果及複習安排。
- 最後一題的前進按鈕改為「查看結果」。

### 5.4 回合結算

- 顯示完成題數、獨立答對題數、練習後答對題數及尚待熟悉題數。
- 列出本回合單字與結果，點選可重新查看解說。
- 提供「加強本回合錯題」、「再練一回合」及「返回首頁」。
- 需加強題數為零時不顯示錯題練習按鈕。
- 即時錯題重練不列入新的首次學習成功數，也不推進間隔複習階段。

### 5.5 單字與進度

- 顯示已接觸單字總數、待複習數及累積完成回合數。
- 提供「全部已學」、「需加強」與「已熟悉」篩選。
- 可搜尋英文拼字或中文意思，並開啟單字解說。
- 空清單顯示原因及「開始練習」入口。

### 5.6 設定

- 音效開關：預設關閉；手動英文朗讀仍可使用。
- 簡短玩法說明與資料儲存說明。
- 「清除學習紀錄」需二次確認，清除後回到初始狀態。

## 6. 學習與複習機制

### 選題順序

- 一般練習：在所選主題內優先選尚未學過的單字；不足時補入已學單字，優先挑選需加強與較久未練習者。
- 到期複習：只取 nextReviewAt 已到期的單字，依到期時間由早到晚，每回合最多 5 題。
- 同一回合不重複；產生回合時固定題目與順序，返回畫面不得重新抽題。
- 同日再次一般練習已學單字時，仍記錄作答；未到期的成功不提前推進複習階段，失敗則重新安排隔日複習。

### 建議的簡化間隔規則

以裝置當地日期計算，每天只允許同一單字推進一次複習階段。

| 事件 | 下次複習 | 階段處理 |
| --- | --- | --- |
| 首次學習獨立答對 | 1 天後 | 設為階段 1 |
| 階段 1 到期複習獨立答對 | 3 天後 | 進入階段 2 |
| 階段 2 到期複習獨立答對 | 7 天後 | 進入階段 3 |
| 階段 3 到期複習獨立答對 | 14 天後 | 進入階段 4，標示已熟悉 |
| 階段 4 到期複習獨立答對 | 14 天後 | 保持階段 4 |
| 任一正式練習需提示、答錯或看答案 | 1 天後 | 重設為階段 0，標示需加強 |
| 階段 0 到期複習獨立答對 | 1 天後 | 回到階段 1 |

「已熟悉」只代表符合本 App 的練習條件，不代表永久記住。即時錯題重練不更動上述排程。

### 今日目標與連續學習

- 每日目標為完成至少 1 個正式回合；不足 5 題的複習回合也算。
- 只有完整結束回合才增加累積回合數與連續學習天數，同日不重複增加天數。
- 今日題數以當天完成判定的正式題目計算；即時錯題重練另外記錄，不重複計入。
- 連續天數依裝置當地日期判斷；跨日未完成回合以實際完成日期記錄。

## 7. 內容規劃

第一版預計內建 150 個基礎單字，每個主題 25 個：食物、動物、日常用品、家庭與人物、動作、形容詞。

每個單字必須包含：

| 欄位 | 說明 |
| --- | --- |
| id | 穩定且唯一的識別值，內容更新不可任意變更 |
| word | 英文基本拼字 |
| meaningZh | 本題對應的繁體中文意思 |
| partOfSpeech | 詞性 |
| topic | 主題 |
| level | 內容難度標籤，如 A1 或 A2 |
| exampleEn | 短且自然的完整英文例句 |
| exampleZh | 對應的繁體中文翻譯 |
| clozePrompt | 已挖空的英文題幹，不直接洩漏答案 |

內容標準：例句使用基礎句型、避免冷僻字；題幹與答案詞形一致；中文意思與例句語意一致；不重複收錄同一拼字。首版以至少 3 個字母的單字為主，確保首尾字母提示不直接揭露完整答案。

詞庫使用自行編寫或確認可合法使用的內容，發佈前完成人工校對。開發時可先用 10–15 題驗證流程，正式第一版須補齊 150 題。

## 8. 資料與技術規劃

- 使用 SwiftUI 建立介面，分離畫面、題目判定、選題與複習排程邏輯。
- 內建詞庫使用專案隨附的結構化檔案；學習紀錄與未完成回合存於本機。
- 儲存技術與最低 iOS 版本在開發前依專案設定確認；此文件不限定尚未驗證的 API。
- 英文朗讀使用系統語音能力；裝置缺少可用語音時顯示提示，不阻擋文字學習。
- 第一版不需要後端、帳號或 API 金鑰，不傳送個人學習資料。

### 核心資料

| 資料 | 必要內容 |
| --- | --- |
| 單字學習紀錄 | 單字 ID、首次學習時間、最後練習時間、作答次數、獨立答對次數、階段、下次複習日期、最近推進日期 |
| 回合紀錄 | 回合 ID、類型、主題、固定題目 ID、開始與完成時間、各題結果 |
| 未完成回合 | 當前題號、輸入文字、嘗試次數、提示次數、是否已揭露答案 |
| 偏好設定 | 音效開關、是否看過說明 |

每題完成時立即保存；回合結算使用唯一回合 ID 避免返回畫面或重啟後重複統計。資料結構保留版本欄位，未來更新不得無故清除使用者進度。

## 9. 介面與品質要求

- 視覺風格清楚、友善、輕量，主要操作容易辨識。
- 支援淺色與深色模式、Dynamic Type 與 VoiceOver。
- 主要觸控區域至少 44 × 44 pt；大字體及鍵盤開啟時仍能捲動至操作按鈕。
- 無障礙標籤須讀出題意、字母數、剩餘次數及結果，作答前不得讀出隱藏答案。
- 遵循減少動態效果設定，成功回饋不可只靠動畫或音效。
- 核心猜字、解說、紀錄與複習可在飛航模式使用；朗讀受裝置可用語音影響。
- 無詞庫或詞庫讀取失敗時，顯示可理解的錯誤與重試入口，不呈現空白頁或崩潰。
- 儲存失敗時保留當前記憶體進度並提供重試，不誤導使用者已成功保存。
- 移除 App 會遺失本機紀錄，於資料說明清楚告知。

## 11. 成效評估

第一版先使用本機紀錄與小規模使用者測試評估，不預設加入遠端分析 SDK。以下為初步驗證目標，並非既有成果：

- 首次體驗：5 位目標使用者中至少 4 位能在無人協助下完成第一回合。
- 使用負擔：一般 5 題回合的完成時間以 3–5 分鐘為設計目標，不設時間限制。
- 學習成效：觀察同一批單字首次學習與 7 天後複習的獨立答對比例，不將提示後成功混入。
- 可持續性：透過訪談了解是否願意每天使用，以及放棄題目的原因。
- 穩定性：驗收時不得出現阻斷核心流程的崩潰、紀錄遺失或重複計分。

## 12. 建議實作順序

1. **可玩原型**：建立小型詞庫、首頁、猜字、判定與解說，驗證題目是否清楚且有學習價值。
2. **學習閉環**：加入結算、本機儲存、中斷恢復、錯題重練與間隔複習。
3. **完整 MVP**：補齊 150 題、主題與搜尋、進度、設定及英文朗讀。
4. **品質驗收**：完成內容校對、無障礙、離線、日期邊界與資料保存測試，再進行小規模試用。

後續可依試用結果考慮聽音猜字、更高難度、個人化每日題數與雲端同步；不影響第一版先完成核心學習流程。
